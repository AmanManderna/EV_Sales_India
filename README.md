# Electric Vehicle Sales by State in India

This project performs exploratory data analysis (EDA) on electric vehicle (EV) sales across different states in India. The goal is to uncover trends, patterns, and insights from a cleaned dataset spanning 2014 to 2023.

## Project Overview

With the growing adoption of electric vehicles in India, understanding sales patterns at the state level is valuable for both business and policy planning. This notebook walks through the steps of data preparation, visualization, and insight generation using Python.

## Dataset Description

- **Source**: Scraped from Clean Mobility Shift and preprocessed for analysis
- **Format**: CSV
- **Total Records**: ~96,000+
- **Features**:
  - `Year`, `Month_Name`, `Date`
  - `State`
  - `Vehicle_Class`, `Vehicle_Category`, `Vehicle_Type`
  - `EV_Sales_Quantity`

## Tools & Technologies

- **Language**: Python
- **Notebook**: Jupyter Notebook
- **Libraries**: pandas, numpy, matplotlib, seaborn

## Key Steps

1. **Data Collection** – Loading and previewing the dataset
2. **Data Preprocessing** – Handling data types and checking for nulls/duplicates
3. **Feature Engineering** – Extracting additional features like month and day
4. **Exploratory Data Analysis** – Visualizing trends across years, states, vehicle types, and more
5. **Insights & Summary** – Drawing conclusions based on visual trends

## Insights

- EV sales have grown significantly since 2019.
- Maharashtra, Karnataka, and Uttar Pradesh are the leading states in EV sales.
- Two-wheelers and four-wheelers dominate the market.
- Sales remain relatively stable month-to-month with slight end-of-year increases.
